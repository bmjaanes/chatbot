Add notes with Siri

Say “Hey Siri, Next Time Note”, tell Siri what to remember, and it's saved for the place you're at. Set it up once in the Shortcuts app:

  1. Open Shortcuts, tap +, and name the shortcut Next Time Note.
  2. Add Ask for Input. Set the question to What do you want to remember for next time?
  3. Add URL Encode. It encodes the Provided Input automatically.
  4. Add Get Current Location.
  5. Add Get Details of Locations and set it to Name, then add another URL Encode.
  6. Add Text and paste this link: https://bmjaanes.github.io/chatbot/?note=NOTE&name=NAME&lat=LAT&lng=LNG Then swap each placeholder for a variable. Tap the variable button above the keyboard: NOTE → the first URL Encoded Text, NAME → the second URL Encoded Text, LAT → Current Location, then tap it and choose Latitude, LNG → Current Location, then Longitude.
  7. Add Open URLs.

Notes from Siri open the web app at bmjaanes.github.io/chatbot in Safari and are saved there. The first time, Shortcuts asks to use your location. Choose Always Allow so Siri doesn't ask again. If Shortcuts can't name the place, the edit screen opens so you can type a name. If it names the street instead of the business, tap Edit to rename it.
